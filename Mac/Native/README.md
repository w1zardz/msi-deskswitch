# MSI DeskSwitch для Mac

Нативное приложение для Apple Silicon, macOS 13 Ventura или новее. В строке меню — короткое стандартное меню с быстрыми действиями; настройки открываются в отдельном окне. Homebrew и Hammerspoon для этой версии не нужны. Утилита `m1ddc` уже внутри приложения.

## Установка

1. Распакуй весь ZIP и запусти `Install.command`. Приложение установится в `~/Applications/MSI DeskSwitch.app` и откроется.
2. Выбери обнаруженный монитор MSI в настройках приложения.
3. Выдай разрешения, которые запросит приложение для горячих клавиш. Запуск при входе включается отдельно в приложении.

При обновлении установщик просит уже запущенный DeskSwitch завершиться, проверяет подпись новой копии и сохраняет предыдущую рядом с именем `MSI DeskSwitch.backup-ДАТА-ВРЕМЯ.app`. Если приложение не закрывается, установка останавливается. Принудительного завершения нет.

Приложение подписано локальной ad-hoc подписью, привязанной к конкретной сборке. После обновления macOS может попросить повторно выдать разрешения, в том числе доступ к горячим клавишам. Устойчивая идентификация приложения между обновлениями требует подписи Apple Developer ID; у этой сборки нет такого сертификата и нотариального заверения Apple. Для скачанной копии macOS может потребовать разрешить запуск в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» после первой попытки открыть приложение. Установщик не снимает quarantine, не меняет Gatekeeper и не выдаёт разрешения за пользователя.

Можно установить вручную: перетащи `MSI DeskSwitch.app` в папку «Программы» своего пользователя и открой. Установщик не обязателен.

## Клавиатура и переключение

В окне настроек выбери горячую клавишу возврата в Windows: **PageDown** или **PageUp**. Переключение компьютера также доступно из меню приложения.

По умолчанию включены две настройки клавиатуры:

- **Сочетания Ctrl как в Windows**: привычные действия вроде копирования и вставки доступны через Ctrl. Обычные сочетания macOS с Cmd продолжают работать. В терминалах Ctrl сохраняет команды оболочки; для копирования и вставки используй Ctrl+Shift+C и Ctrl+Shift+V.
- **Alt+Shift — смена языка**: перебирает включённые источники ввода macOS. Нужные языки добавляются в системных настройках клавиатуры.

Обе настройки можно выключить отдельно в окне приложения. Для глобальных клавиш потребуется разрешение macOS, которое приложение поможет открыть.

Cmd+Tab остаётся штатным переключением приложений Mac. Колпачки Option/Command могут не совпадать со схемой NuPhyIO; перестановка их действий в macOS меняет также физическую комбинацию Alt+Shift. В текущей настройке сохранены прежние модификаторы и привычная смена языка. Колпачки разного размера переставлять не нужно.

Чтобы сохранить штатные Ctrl, Option и PageDown встроенной клавиатуры MacBook, используй [отдельный профиль NuPhy для Karabiner-Elements](../../NuPhy/karabiner/README.md). Он добавляет Windows-сочетания только для Air100 V3. После проверки профиля отключи в DeskSwitch его глобальные Ctrl-сочетания, Alt+Shift и отдельную PageDown: профиль передаёт переключение монитора через запасное сочетание Ctrl+Shift+F11. Не включай оба обработчика одних сочетаний одновременно. Перехват клавиш громкости GoXLR в версии 2.1 настраивается отдельно и пока действует на все клавиатуры Mac.

## Ручка громкости GoXLR

В версии 2.2 меню **«Звук»** позволяет выбрать **«Динамики MacBook»** или **«Наушники GoXLR»**. Такой же выбор есть в настройках. При выборе динамиков крутилка и другие клавиши громкости регулируют обычную громкость Mac; управление Headphones автоматически приостанавливается. При возврате в GoXLR оно снова действует, если включено. Нажатие NuPhy остаётся Delete.

Выбор сохраняется и восстанавливается после переподключения USB. Запоминается точный выход: при смене USB-порта и идентификатора GoXLR выбери его заново. Без явного выбора приложение не меняет выход macOS. Переключаются общий звук и системные сигналы; микрофон, профили и уровни GoXLR сохраняются. Приложения с собственным явно выбранным аудиовыходом нужно переключать внутри этих приложений.

В версии 2.1 появился раздел **«Наушники GoXLR»**. Нужен уже настроенный GoXLR Utility с твоими профилями. Обнови список, выбери свой GoXLR по серийному номеру и включи управление. Порт локального API задаётся в раскрывающемся разделе подключения; начальное значение — 14564. Приложение соединяется только с `127.0.0.1`.

Поворот NuPhy с назначениями Volume Up / Down меняет Headphones примерно на 2 процентных пункта за шаг. **Нажатие ручки остаётся Delete**, как в Windows. Отдельная медиаклавиша Mute или кнопка выключения звука в настройках отключает наушники и возвращает прежний подтверждённый уровень; назначать Mute нажатию ручки не требуется. Включённый перехват действует также на другие клавиши громкости Mac. После ошибки или переподключения неизвестная громкость не восстанавливается автоматически. Кнопки в настройках позволяют проверить управление отдельно от клавиатуры.

Перенос профилей, каналы и настройка Windows описаны в [инструкции GoXLR](https://github.com/w1zardz/msi-deskswitch/blob/master/Mac/GoXLR.md). DeskSwitch не устанавливает Utility и не меняет микрофонные профили или маршрутизацию.

## Если раньше использовался Hammerspoon

В `~/.hammerspoon/init.lua` убери или закомментируй только строку, подключающую `desk-switch`, например `deskSwitchMSI = require("desk-switch")`, затем выбери **Reload Config** в меню Hammerspoon. Это освобождает PageDown для нового приложения. Другие модули Hammerspoon продолжат работать.

Установщик сообщает о найденном старом модуле, но не редактирует конфигурацию Hammerspoon. Старая Lua-версия и её установщики в репозитории сохранены.

## Удаление и возврат к предыдущей версии

Выключи запуск при входе, выйди из DeskSwitch через его меню и перенеси приложение в Корзину. Для отката перенеси новую копию в Корзину, переименуй сохранённую `MSI DeskSwitch.backup-….app` обратно в `MSI DeskSwitch.app` и открой. Настройки пользователя остаются на месте.

## Сборка

На Mac с установленными Xcode Command Line Tools и Python 3:

```sh
Mac/Native/build.sh --output dist/DeskSwitch-Mac-Native.zip
```

Результат: `dist/native/MSI DeskSwitch.app`, установщик и документация. `--output` необязателен; без него ZIP не создаётся. `--cache /path/cache` задаёт каталог кэша архивов. Цель сборки — `arm64-apple-macos13.0`, версия приложения — `2.1.0`.

Первой сборке нужен интернет для скачивания закреплённого Homebrew arm64 Ventura bottle `m1ddc 1.2.0`. Повторные сборки используют `.cache/`. Перед извлечением проверяется SHA-256 `fd4b3c88cd24a1992cb6eb8fa0c82edc301ef5831de19416cc5691c758b4b03d`; бинарник проверяется на arm64 и зависимости только из `/usr/lib/` и `/System/Library/`. В приложение попадают его лицензия, лицензия DeskSwitch и `THIRD_PARTY.md`.

Скрипт собирает Swift-приложение, рисует иконку через AppKit, подписывает вложенный бинарник и пакет, затем проверяет целостность подписи. Homebrew и Python не нужны для запуска готового приложения.
