# GoXLR через MSI MAG322UPF: Mac и Windows

Схема предназначена для полноразмерного GoXLR с отдельным питанием. DeskSwitch переключает вход монитора, а KVM монитора передаёт USB выбранному компьютеру. GoXLR подключён к одному компьютеру за раз.

## Подключение

```text
Windows ── DisplayPort + USB-B ──┐
                                MSI MAG322UPF, KVM Auto
Mac ────── USB-C (видео/данные) ──┘
                                ├── USB-A → GoXLR → наушники и микрофон
                                ├── USB-A → NuPhy
                                └── USB-A → Logi Bolt

GoXLR → собственный блок питания
```

Хаб нужен только при нехватке свободных портов. В [официальной инструкции MAG322UPF](https://download-2.msi.com/archive/mnu_exe/monitor/MAG_322UPFv1.1_English.pdf) указаны **три USB 2.0 Type-A**; USB-B является входом от компьютера и не заменяет порт для периферии. Перед покупкой проверь доступность всех USB-A своей ревизии монитора.

Если свободных портов нет, практичный вариант — USB-хаб на четыре порта с передачей данных и отдельным питанием. GoXLR лучше оставить непосредственно в мониторе, клавиатуру и Bolt подключить через хаб. Всё по-прежнему переключается штатным KVM. Скорость устройств за хабом ограничена USB 2.0 монитора; USB 3.x хаб эту границу не повышает. Работоспособность конкретного хаба нужно проверить после подключения.

Количество CoreAudio-каналов не означает столько физических разъёмов. Устройство публикует многоканальные потоки для микширования. Выбор предпочтительных стереоканалов также не гарантирует одинаковый выбор входа всеми программами — микрофон нужно проверить в используемых приложениях.

Если после переключения исчез звук, сначала проверь, виден ли GoXLR в звуковых устройствах Mac. Одновременное исчезновение GoXLR, NuPhy и Bolt означает, что USB-хаб монитора сейчас недоступен Mac; выбор аудиоканала этого не исправит. В проверенном случае повторный выбор **«На MacBook»** в DeskSwitch вернул USB и звук. Если USB уже вернулся, но выход остался другим, выбери GoXLR в настройках звука. DeskSwitch 2.1 сам системный аудиовыход не меняет. Не сбрасывай профиль микшера для этой проверки.

## Программное обеспечение и профили

Для управления микшером на Mac подходит сторонний открытый проект [GoXLR Utility](https://github.com/GoXLR-on-Linux/goxlr-utility). Его авторы поддерживают полноразмерный GoXLR, macOS и импорт профилей официального Windows-приложения. Это community-проект; авторы всё ещё отмечают экспериментальный статус macOS. Не запускай его одновременно с отдельным проектом GoXLR-MacOS.

Проверен upstream-релиз **v1.2.4**: `goxlr-utility-macos-1.2.4-m1.pkg`, SHA-256 `2799d0861592e6bbd4fc21b4d6bf9c7c475c9306785c9ae61da5ee9f8da50468`. Скачивание: [официальный репозиторий проекта](https://github.com/GoXLR-on-Linux/goxlr-utility/releases/tag/v1.2.4). В пакете есть системный помощник инициализации USB; его установка требует администратора. У пакета нет подписи Apple.

**Перед первым запуском перенеси сохранённый основной профиль и профиль микрофона из Windows.** Обычно они лежат в `Документы\GoXLR`; если расположение изменено, открой папку профилей из самого приложения. Сохрани текущие настройки в Windows перед копированием. Для кнопок сэмплера нужны также исходные аудиофайлы сэмплов.

Для переноса профилей запусти `Export-GoXlrProfiles.cmd` из нового Windows-пакета DeskSwitch. Он собирает только `.goxlr` и `.goxlrMicProfile` из `Документы\GoXLR` (или выбранной папки) в ZIP на рабочем столе, требует оба типа и не меняет исходники. Сэмплы, логи и другие файлы не включаются; архив никуда автоматически не отправляется. CMD запускает вложенный PowerShell-скрипт с разрешением выполнения только для этого процесса, не меняя системную политику. Перенеси полученный ZIP на Mac.

Для первого запуска Utility на Windows подготовлен `Import-GoXlrProfiles.cmd`: он читает отдельный `GoXLR-Import.json` с явно выбранными именами профилей, serial и SHA256 архива/двух файлов. Личный manifest и ZIP передаются отдельно и не публикуются в репозитории. Помощник копирует только выбранные файлы и их стартовые алиасы, затем настраивает Utility и DeskSwitch. Отличающиеся существующие файлы Utility не заменяет. Прежний небольшой конфиг DeskSwitch сохраняется один раз атомарно; повреждённая копия вызывает отказ. Сначала закрой оба приложения GoXLR и DeskSwitch, выполни импорт, затем установи Utility и запусти `Install.cmd` из Windows-пакета DeskSwitch. У Utility включи автозапуск; у официального GoXLR App отключи его, сохранив драйвер.

Это нужно для сохранения твоего звука: в [исходниках v1.2.4](https://github.com/GoXLR-on-Linux/goxlr-utility/blob/v1.2.4/daemon/src/device.rs) подключение устройства применяет основной профиль и профиль микрофона, а при отсутствии выбранных файлов использует стандартные. Перед первым запуском нужно подготовить файлы и выбор стартовых профилей для этого устройства; один лишь импорт файлов не означает, что они будут выбраны при подключении. В проверенной связке оба выбранных владельцем профиля уже перенесены на Mac и сохранены в настройках устройства.

Согласно инструкции проекта, профили копируются в каталоги, открываемые кнопкой папки в панелях Main и Mic. После импорта нужно отдельно выбрать загруженные профили. На Mac перенос и повторное подключение проверены. Файлы профилей не переносят отдельные VST-фильтры OBS, даже если их названия указаны в имени профиля.

## Как разложить звук

GoXLR Utility создаёт именованные CoreAudio-устройства через Aggregate Manager, пока программа работает. На macOS Tahoe штатный поиск через IOAudioEngine может не находить USB-аудиоустройство: для этого в репозитории сохранена [проверенная поправка для v1.2.4](GoXLR-Utility/README.md). Таблица каналов взята из [исходников v1.2.4](https://github.com/GoXLR-on-Linux/goxlr-utility/blob/v1.2.4/daemon/src/platform/macos/device.rs).

| Назначение | Канал GoXLR | Стероканалы физического USB-устройства |
| --- | --- | --- |
| Обычный звук Mac | System | Выход 1–2 |
| Игры | Game | Выход 3–4 |
| Голоса собеседников | Chat | Выход 5–6 |
| Музыка | Music | Выход 7–8 |
| Сэмплер | Sample | Выход 9–10 |
| Общий микс для записи/стрима | Stream Mix | Вход 1–2 |
| Микрофон для звонков | Chat Mic | Вход 3–4 |
| Запись сэмплера | Sampler | Вход 5–6 |

У приложения должна быть возможность выбрать нужное устройство вывода. Если оно этого не умеет, отдельный маршрутизатор аудио рассматривается по необходимости. Не подставляй Stream Mix в звонки вместо Chat Mic: собеседник может получить весь звук компьютера в зависимости от маршрутизации микшера.

## Ручка NuPhy и Headphones

Схема для обеих систем: вращение — небольшими шагами менять **Headphones GoXLR**, **нажатие — Delete**. Назначение нажатия сохраняется; выключение микрофона остаётся на отдельной кнопке GoXLR.

В DeskSwitch 2.1 для Mac и текущих исходниках Windows добавлен перехват обычных команд Volume Up / Volume Down / Mute. Для вращения NuPhy используются Volume Up / Volume Down; нажатие оставляем назначенным на Delete. Команда Mute доступна отдельной медиаклавише и кнопке в настройках DeskSwitch. Перехват относится также к другим клавишам громкости компьютера. Прошивка клавиатуры не меняется; на USB-аудиоинтерфейсе обычная системная громкость может быть недоступна.

1. Подготовь и выбери свои основной и микрофонный профили в **GoXLR Utility на каждом компьютере**. Сохраняй текущие настройки перед переносом. Официальное приложение TC-Helicon не предоставляет используемый этой интеграцией API; один только его запуск не заменяет Utility.
2. В DeskSwitch на Mac открой настройки «Наушники GoXLR»; на Windows — раздел GoXLR в меню трея. Обнови список и явно выбери серийный номер своего устройства. Автоматической подстановки первого GoXLR нет.
3. Включи управление громкостью. Если локальный API Utility настроен на другой порт, укажи этот порт в DeskSwitch; начальное значение — 14564. Подключение разрешено только к `127.0.0.1`, без прокси и перенаправлений.
4. Проверь сначала кнопки громкости в настройках, затем вращение ручки. Один шаг изменяет Headphones на 5 из 255 — примерно 2 процентных пункта. Нажатие ручки должно выполнять Delete. Отдельная команда Mute или кнопка выключения звука в настройках отключает наушники; повторное действие восстанавливает подтверждённую громкость до выключения. Это не mute микрофона.

Перед изменением DeskSwitch читает текущий Headphones через `GetStatus`, затем отправляет `SetVolume` выбранному устройству. Поэтому ручка учитывает изменения из интерфейса Utility. Быстрые однонаправленные повороты объединяются; смена направления сохраняет порядок. Все значения ограничены диапазоном 0–255.

При ошибке, отключении устройства, сне или смене настроек очередь и запомненная громкость сбрасываются. Неподтверждённая команда не повторяется автоматически. Если Headphones уже равен нулю и прежняя громкость неизвестна, mute не подставляет случайный уровень: вращение вверх начнёт тихо с нуля. После подключения к другому компьютеру сохранённый на первом уровень не переносится.

Интеграция не устанавливает Utility, не применяет профили и не меняет маршрутизацию, усиление микрофона или уровни других каналов. Автоматические тесты проверяют протокол, очередь и обработку клавиш; они не заменяют проверку реальной ручки и наушников.

## Ограничения USB-KVM

- При переключении USB разрывается и подключается заново. Звонок или запись могут потребовать повторного выбора устройства.
- Одновременного USB-звука от Windows и Mac нет. Для него нужна отдельная аудиосхема.
- До подтверждения звука, микрофона, холодного запуска и нескольких циклов Mac → Windows → Mac эта конкретная конфигурация остаётся на этапе проверки.
