# Резервная копия NuPhy Air100 V3

Снимок от **12 сентября 2026**, получен штатным экспортом **NuPhyIO 2.2.7** с подключённой клавиатуры. Сохранены оба режима: **M1 Mac** и **M2 Windows**. При экспорте был активен M2 Windows; назначения клавиш не менялись.

## Что сохранено

В каждом режиме сохранены все четыре слоя назначений (по 110 двухбайтовых позиций), полные 2048 байт памяти макросов, настройки подсветки, функций клавиатуры, сна и дополнительные назначения. Оригинальные JSON не изменены.

В каждом режиме сейчас **0 активных макросов из 32 слотов**: все указатели слотов пусты. Остаточная память сохранена целиком. Привычные Ctrl+C / Ctrl+V и Alt+Shift на Mac реализованы приложением [DeskSwitch](../Mac/Native/README.md), а не записанными макросами NuPhy. Его исходники находятся в этом же репозитории.

Проверены все семь встроенных SHA-256 контрольных сумм каждого экспорта. M1 и M2 различаются во всех четырёх слоях; это два самостоятельных снимка. Фактический импорт обратно в клавиатуру не выполнялся, чтобы не перезаписывать работающую конфигурацию.

## Где бэкап

`backups/2026-09-12/air100-v3.tar.gz.age` содержит оба исходных JSON. `manifest.json` рядом описывает состав и контрольные суммы исходных файлов.

Репозиторий публичный, поэтому архив зашифрован стандартным **age**. Экспорт NuPhy содержит необнулённую память неактивных макросов; её нельзя считать очищенной от ранее набранного текста. Ключ восстановления хранится отдельно от Git, в личной копии бэкапа владельца. Без этого ключа расшифровать архив нельзя. Сохрани личную копию вместе с ключом в своём хранилище.

Если исходные JSON из личной копии уже доступны, расшифровка не нужна. Иначе в Терминале на Mac, находясь в папке `NuPhy` репозитория:

```sh
brew install age
age --decrypt --identity /путь/к/recovery-key.txt \
  --output air100-v3.tar.gz backups/2026-09-12/air100-v3.tar.gz.age
mkdir restored
tar -xzf air100-v3.tar.gz -C restored
```

Расшифровка проверена побайтовым сравнением с исходным архивом. После распаковки проверь SHA-256 JSON по `manifest.json`.

## Восстановление в NuPhyIO

1. Подключи Air100 V3 и открой NuPhyIO. Перед восстановлением экспортируй текущие режимы, если в них появились новые изменения.
2. Открой список конфигураций нажатием на текущий режим сверху справа.
3. В меню `…` у **M1 Mac** выбери **Import / Импорт** и файл `NuPhy-Air100V3-M1-Mac-2026-09-12.json`.
4. В меню `…` у **M2 Windows** импортируй `NuPhy-Air100V3-M2-Windows-2026-09-12.json`.
5. Дождись окончания записи и выбери **M2 Windows** для текущей схемы DeskSwitch.

Импорт заменяет настройки выбранного режима. Не используй «Сброс» и не импортируй эти файлы в другую модель клавиатуры. Для восстановления предпочтительна та же версия NuPhyIO; совместимость будущих версий не проверялась.

## Привычное расположение клавиш

Физически у владельца стоят **Ctrl → Opt → Cmd → пробел**. Колпачки Opt и Cmd разного размера, подходящего запасного Opt нет: **оставляем их на месте**. Надписи колпачков не определяют отправляемые команды. Системная перестановка Option/Command на Mac была отменена по просьбе владельца, чтобы сохранить привычное физическое сочетание смены языка.

В M2 Windows средняя клавиша передаёт Command/Windows, ближайшая к пробелу — Option/Alt. На Mac DeskSwitch сохраняет привычные сочетания Ctrl и переключение языка Alt+Shift. Красная верхняя правая клавиша — **PGDN**, она переключает компьютер. Fn, правый Ctrl и остальные клавиши переставлять не требуется.

## Крутилка: поворот — громкость, нажатие — Delete

**Нажатие ручки остаётся Delete на Mac и Windows.** Поворот передаёт Volume Down / Volume Up; при включённой [интеграции GoXLR](../Mac/GoXLR.md#ручка-nuphy-и-headphones) эти команды меняют именно Headphones. Отдельная медиаклавиша Mute и кнопка выключения звука в DeskSwitch доступны независимо от ручки.

В сохранённых экспортах от 12 сентября проверены оба режима, M1 Mac и M2 Windows: на всех четырёх слоях нажатие ручки имеет код **`0x004C` — Delete вперёд**, а поворот — **`0x00AA` / `0x00A9` — Volume Down / Volume Up**. Это состояние резервной копии; оно не заменяет проверку после будущего переназначения клавиш в NuPhyIO. Прошивку и текущее назначение кнопки для подключения Headphones менять не нужно.

## Отдельные сочетания для внешней клавиатуры

Для схемы «NuPhy как в Windows, встроенная клавиатура MacBook как обычно» подготовлен [профиль Karabiner-Elements](karabiner/README.md). Он ограничен событиями Air100 V3, сохраняет текущие физические модификаторы и добавляет Alt+Tab с удержанием. Это отдельная настройка macOS; прошивка NuPhy и Windows не меняются. Установка профиля и проверка на реальной клавиатуре выполняются отдельно от восстановления резервной копии.

12 сентября профиль **DeskSwitch NuPhy** применён на MacBook владельца. Владелец подтвердил Ctrl+C/V, прежний Alt+Shift и удержание Alt+Tab с обратным Shift+Tab и продолжением после отпускания Shift. Встроенная клавиатура исключена из перехвата по её фактическим идентификаторам; в установленной конфигурации также исключён клавиатурный интерфейс Bolt. Общие Ctrl/Alt+Shift/PageDown в DeskSwitch выключены, приложение перезапущено. Для NuPhy настроены обычные F1–F12; PGDN передаёт запасное сочетание с учётом режима F-клавиш macOS. После этого изменения владелец повторно подтвердил физическое переключение PGDN из Mac в Windows и обратно.
