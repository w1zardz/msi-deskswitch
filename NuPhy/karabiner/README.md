# NuPhy как Windows, встроенная клавиатура как Mac

Профиль предназначен именно для **NuPhy Air100 V3, USB `19f5:102d`**, в режиме **M2 Windows**. Встроенная клавиатура MacBook не подходит под условия этих правил, даже когда NuPhy подключена. Беспроводные приёмники с другими идентификаторами автоматически не подхватываются.

Нужен [Karabiner-Elements 16.3 или новее](https://karabiner-elements.pqrs.org/). Сам DeskSwitch управляет монитором и GoXLR; Karabiner применяет сочетания к событиям конкретной клавиатуры.

Изоляция здесь относится к Ctrl, Alt+Shift, Alt+Tab и PGDN. Обработчик громкости GoXLR в DeskSwitch 2.1 пока общий для медиаклавиш Mac: при его включении он может перехватывать и встроенные клавиши громкости. Этот профиль не меняет обработку громкости.

## Клавиши

Колпачки оставляем **Ctrl → Opt → Cmd → пробел**. В режиме M2 они отправляют **Control → Command/Windows → Option/Alt**. Поэтому привычный физический Alt — клавиша возле пробела с надписью Cmd. Переставлять колпачки или менять Option и Command в macOS не нужно.

| На NuPhy | На Mac |
|---|---|
| Ctrl+C / V / X / A / Z / Y | Копировать, вставить, вырезать, выделить всё, отменить, повторить |
| Ctrl+S / F / W / R / T / O / P / L / N | Привычные действия приложения через Command |
| Ctrl+← / → / Backspace / Delete | Перемещение и удаление по словам |
| Home / End | Начало / конец строки; Shift выделяет |
| Ctrl+Home / End | Начало / конец документа; Shift выделяет |
| Alt+Tab | Штатный переключатель **приложений** Mac |
| Удерживать Alt, нажимать Tab / Shift+Tab | Вперёд / назад; отпустить Alt — выбрать |
| Короткое Alt+Shift | ABC ↔ Русская — ПК |
| Красная PGDN | Переключить монитор после отпускания |
| F1–F12 в новом профиле | Обычные функциональные клавиши, как в Windows |

Обычный Cmd+Tab и Ctrl+Tab не переназначаются. В Terminal, iTerm2, Warp, Alacritty, Kitty и WezTerm команды Ctrl остаются командами оболочки; копирование и вставка — Ctrl+Shift+C / V.

Alt+Shift использует стандартный `to_if_alone`: можно нажать модификаторы в любом порядке, слева или справа. Язык меняется при отпускании **модификатора, нажатого вторым**, если он удерживался менее 1,5 секунды. Добавление буквы, Tab, кнопки мыши или прокрутки отменяет смену языка. Это короткое сочетание для отпущенных остальных клавиш; уже удерживаемые до него буквы не отслеживаются отдельным состоянием. Другие источники ввода не переключаются случайно: правила явно описывают только ABC и RussianWin.

Переключатель остаётся штатным macOS: это выбор приложений, а не отдельное окно каждого приложения как в Windows. Никакого нового переключателя окон профиль не устанавливает.

## Установка

1. Установи и открой Karabiner-Elements, включи запрошенные macOS службы и разрешения. В EventViewer → Devices проверь NuPhy: vendor `6645`, product `4141`; в Devices разреши обработку этой клавиатуры.
2. Запусти `Install.command` из этой папки. При существующей конфигурации явно выбери профиль по номеру. При первой установке создаётся единственный профиль **DeskSwitch NuPhy**, с типом клавиатуры **ANSI** и обычными F1–F12 именно для Air100 V3. Штатная команда Karabiner читает подключённые устройства; встроенная клавиатура MacBook получает `ignore: true` по её точному идентификатору, чтобы Karabiner вообще не перехватывал её события. Сама клавиатура продолжает работать. Если устройства пока недоступны или их нельзя однозначно определить, установщик объясняет причину и не записывает файл. Если у тебя уже есть профили, их тип клавиатуры, список устройств и текущий выбор не меняются.
3. Выбери нужный профиль в Karabiner. В DeskSwitch выключи **Ctrl-сочетания**, **Alt+Shift** и **прямую PGDN**: иначе два обработчика будут менять одну комбинацию. Сам DeskSwitch и запасное **Ctrl+Shift+F11** оставь включёнными — профиль посылает это сочетание после отпускания PGDN.
4. В настройках macOS оставь источники ввода **ABC** и **Русская — ПК**, а назначения Option/Command — прежними. Профиль не меняет прошивку NuPhy, Windows и настройки GoXLR.

PGDN учитывает системный режим функциональных клавиш автоматически. Даже если F11 у Mac обычно уменьшает громкость, нажатие PGDN отправляет переключателю команду монитора; менять общие настройки F-клавиш MacBook не требуется.

Установщик заменяет только правила с префиксом `DeskSwitch NuPhy —` внутри **выбранного** профиля и сохраняет все остальные правила/настройки. Перед первой заменой сохраняет один локальный `karabiner.before-deskswitch.json`. Существующее простое переназначение модификаторов вызывает отказ с объяснением, а не молчаливую замену. Python 3 нужен только установщику; `deskswitch-nuphy.json` можно импортировать через Complex Modifications вручную.

Для явного выбора из терминала:

```sh
python3 install.py --profile 'Точное имя профиля'
```

## Проверка после включения

- На NuPhy: Ctrl+C/V и Alt+Shift на **прежних физических клавишах**.
- Удерживая Alt: Tab несколько раз, Shift+Tab, отпустить Shift, снова Tab; меню остаётся до отпускания Alt.
- Alt+Shift+буква и Alt+Shift+Tab не меняют язык.
- В Terminal Ctrl+C останавливает команду; Ctrl+Shift+C/V копирует/вставляет.
- На встроенной клавиатуре MacBook Ctrl и Option остаются штатными, Cmd+C/V/Tab работают, пока NuPhy тоже подключена.
- PGDN переключает монитор один раз после отпускания; после возвращения через USB кнопки и модификаторы не застревают.

Автоматические проверки структуры, политики сочетаний и сохранения чужих настроек:

```sh
python3 generate.py
python3 test_profile.py
```

Они не заменяют физическую проверку USB-клавиатуры и поведения системного переключателя.

## Почему именно так

- [`device_if`](https://karabiner-elements.pqrs.org/docs/json/complex-modifications-manipulator-definition/conditions/device/) проверяет источник события; `device_exists_if` изменил бы и встроенную клавиатуру при подключённой NuPhy.
- [`to_if_other_key_pressed`](https://karabiner-elements.pqrs.org/docs/json/complex-modifications-manipulator-definition/to-if-other-key-pressed/) меняет удерживаемый Option в Command после Tab. Документация отдельно объясняет, почему простая замена Alt+Tab не сохраняет удержание при Shift.
- [`to_if_alone`](https://karabiner-elements.pqrs.org/docs/json/complex-modifications-manipulator-definition/to-if-alone/) отменяет одиночное действие при добавлении других клавиш.
- [`select_input_source`](https://karabiner-elements.pqrs.org/docs/json/complex-modifications-manipulator-definition/to/select-input-source/) выбирает конкретную раскладку без подмены системного сочетания смены языка.
