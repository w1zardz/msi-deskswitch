# MSI DeskSwitch

Одна красная **PageDown** на NuPhy Air100 V3 переключает MSI MAG 322UPF, клавиатуру и мышь между Windows и Mac на Apple Silicon.

На Windows кнопка выбирает USB-C (Mac), на Mac — DisplayPort (Windows). Переключение происходит после отпускания кнопки. Запасное сочетание: **Ctrl+Shift+F11**. PageDown без модификаторов занята переключателем, пока он работает. Прошивка и раскладка NuPhy не меняются.

## Подключение

```text
Windows ── DisplayPort ──┐
Windows ── USB-A → USB-B ┤
                        ├── MSI MAG 322UPF ── NuPhy по USB (Wired)
Mac ────── USB-C ────────┘                 └─ приёмник Logi Bolt
```

- В меню MSI: **KVM → Auto**, DDC/CI включён.
- USB-C должен передавать видео и данные. Mac должен быть подключён и разбужен.
- NuPhy остаётся в **Wired**. Приёмник Bolt вставлен в USB-порт монитора; мышь использует канал, спаренный с этим приёмником.
- Другие мониторы, подключённые только к Windows, остаются на Windows.
- USB-устройства переподключаются с задержкой в несколько секунд.

## Установка на Windows

Скачай `DeskSwitch-Windows.zip` из [Releases](https://github.com/w1zardz/msi-deskswitch/releases/latest), распакуй и запусти `Install.ps1` через PowerShell. Для обновления сначала выбери «Выход» у значка DeskSwitch в трее.

Программа устанавливается в `%LOCALAPPDATA%\MSI-DeskSwitch` и добавляет ярлык в автозагрузку текущего пользователя. Администратор не требуется. Исходники собираются `Windows/Build.ps1` компилятором .NET Framework, входящим в Windows. Для ручного запуска достаточно `DeskSwitch.exe`.

**PageDown → Mac.** Также можно дважды нажать значок в трее или открыть его меню.

## Установка на Mac

Скачай `DeskSwitch-Mac.zip` из [Releases](https://github.com/w1zardz/msi-deskswitch/releases/latest). Нужны Apple Silicon и macOS 13+.

1. Распакуй архив и открой `Install.command`.
2. Разреши Hammerspoon управление в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
3. В меню Hammerspoon сверху нажми **Reload Config**. Появится меню **Mac ↔ PC**.

**PageDown → Windows.** Разрешение macOS требуется выдать самостоятельно. Пакет содержит Hammerspoon 1.1.1 и m1ddc 1.2.0; Homebrew и инструменты разработчика для этого варианта не нужны. Установщик проверяет SHA-256 архивов и подпись нового Hammerspoon, сохраняет предыдущую конфигурацию и добавляет строку загрузки модуля. Установленный Hammerspoon сохраняется. Автозапуск включается при загрузке модуля.

Для пользователей Homebrew: `Mac/Install.command` устанавливает зависимости через Homebrew и ту же конфигурацию. Готовый архив из Releases проще.

## Исправление колеса MX Master 3S

После переноса Bolt между компьютерами мышь может сохранять режим HID++: обычные щелчки и движение работают, а вращение колеса не поступает в Windows. Режим высокой точности также может давать неправильную скорость прокрутки.

Windows-версия при запуске и уведомлении о переподключении USB находит **MX Master 3S** на **Logi Bolt `046D:C548`**, запрашивает индекс HID++ feature `0x2121` и возвращает колесо в обычный режим HID с обычной точностью. Изменение проверяется повторным чтением. Направление прокрутки сохраняется. SmartShift, магнитные щелчки, чувствительность указателя, кнопки и спаривание не меняются. Если запущен Logitech Options, управление колесом остаётся ему.

В меню трея есть «Восстановить прокрутку MX Master 3S». Другие модели автоматически не перенастраиваются.

## Диагностика

```powershell
DeskSwitch.exe status input.txt
DeskSwitch.exe wheel-status wheel.txt
DeskSwitch.exe repair-wheel wheel.txt
DeskSwitch.exe mac
DeskSwitch.exe windows
```

`status` читает вход монитора. Команды `mac` и `windows` немедленно меняют вход. Журнал Windows: `%LOCALAPPDATA%\MSI-DeskSwitch\status.log`. Журнал установки Mac: рядом с `Install.command`.

Если на Mac не работает возврат: проверь разрешение Hammerspoon, Reload Config, подключение USB-C и наличие MSI в выводе `m1ddc display list`. В меню монитора можно вручную выбрать DisplayPort. Автовыбор Mac при появлении дисплея по умолчанию выключен.

## Что проверено

- Команды DDC из Windows действительно переключают MSI между DisplayPort (`15`) и USB-C (`16`).
- NuPhy в Wired и мышь через Bolt работают на обоих компьютерах через встроенный KVM.
- Восстановление режима колеса `3 → 0` устранило отсутствие прокрутки и неправильную скорость на Windows.
- Windows-программа собирается; чтение режима колеса через её собственный HID-код проверено на устройстве.
- Архив Mac проверен на целостность, executable-права установщика и зависимости m1ddc.

Установка Hammerspoon и обратное переключение по кнопке на конкретном Mac требуют проверки после выдачи разрешения macOS. Другие модели MSI, другие USB-C контроллеры и Intel Mac не заявлены как проверенные.

## Удаление

Windows: выйди из приложения, удали ярлык `MSI DeskSwitch.lnk` из автозагрузки и папку `%LOCALAPPDATA%\MSI-DeskSwitch`.

Mac: убери `deskSwitchMSI = require("desk-switch")` из `~/.hammerspoon/init.lua`, затем Reload Config. При необходимости удали `desk-switch.lua` и `desk-switch-bin`. Резервные копии прежних файлов создаются с суффиксом `.backup-...`. Автозапуск Hammerspoon можно выключить в его настройках.
