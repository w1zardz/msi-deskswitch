# MSI DeskSwitch

Одна красная **PageDown** на NuPhy Air100 V3 переключает MSI MAG 322UPF, клавиатуру и мышь между Windows и Mac на Apple Silicon.

На Windows кнопка выбирает USB-C (Mac), на Mac — DisplayPort (Windows). Переключение происходит после отпускания кнопки. Запасное сочетание: **Ctrl+Shift+F11**. PageDown без модификаторов занята переключателем, пока он работает. Прошивка и раскладка NuPhy не меняются.

## Подключение

```text
Windows ── DisplayPort ──┐
Windows ── USB-A → USB-B ┤
                        ├── MSI MAG 322UPF ── NuPhy по USB (Wired)
Mac ────── USB-C ────────┘                 └─ приёмник Logi Bolt
```

- В меню MSI: **KVM → Auto**, DDC/CI включён.
- USB-C должен передавать видео и данные. Mac должен быть подключён и разбужен.
- NuPhy остаётся в **Wired**. Приёмник Bolt вставлен в USB-порт монитора; мышь использует канал, спаренный с этим приёмником.
- Другие мониторы, подключённые только к Windows, остаются на Windows.
- USB-устройства переподключаются с задержкой в несколько секунд.

### GoXLR через USB монитора

Полноразмерный **GoXLR** можно включить в эту схему через USB-KVM MSI: USB-кабель GoXLR подключается к USB-A монитора, отдельное питание GoXLR остаётся подключённым. Наушники и микрофон остаются в GoXLR; USB-аудиоустройство переходит к выбранному компьютеру.

**Статус проверки на Mac, 12.09.2026:** GoXLR обнаружен через монитор как USB-аудиоустройство TC-Helicon, 23 входных и 10 выходных каналов, 48 кГц. Владелец подтвердил слышимый звук в наушниках после теста нескольких выходных пар. Установлена Utility с поправкой для macOS Tahoe: выход System и вход Chat Mic. Аппаратный сигнал микрофона и два возврата USB проверены; запись в приложениях и сон ещё требуют проверки.

В версии Mac 2.1 и текущих исходниках Windows реализовано **вращение ручки NuPhy → Headphones GoXLR**: громкость меняется небольшими шагами. **Нажатие ручки остаётся Delete на Mac и Windows**. Нужен настроенный GoXLR Utility на каждом компьютере, явный выбор устройства в DeskSwitch и включение функции. Отдельная медиаклавиша Mute и кнопка выключения звука в настройках по-прежнему управляют звуком наушников. На Mac и Windows Utility настроена, профили перенесены; владелец подтвердил слышимый звук и изменение громкости крутилкой на обоих компьютерах.

Запись на Windows: [схема OBS с отдельной громкостью наушников и дорожками](Windows/OBS-GoXLR.md).

**Mac 2.2:** в меню «Звук» можно переключаться между динамиками MacBook и наушниками GoXLR. Крутилка следует выбранному выходу, нажатие остаётся Delete. Выбор выхода сохраняется после USB-переподключения; микрофон и профили не меняются.

При управлении Headphones из DeskSwitch появляется небольшая шкала **«Наушники · 42%»** внизу экрана с указателем мыши. Она показывает уровень после подтверждения GoXLR Utility, обновляется при поворотах и исчезает через 1,1 секунды после последнего ответа. Шкала не забирает фокус и пропускает клики; обновление списка устройств само по себе её не открывает. При ошибке, смене устройства или приостановке управления она скрывается. Функция включена в текущие исходники Windows и Mac; для её появления нужна новая сборка приложения.

На Windows каждый поворот явно поднимает шкалу поверх других окон и сразу перерисовывает её без активации. Это устраняет случай, когда программа считала шкалу видимой, но другое окно поверх остальных перекрывало её. Исправленная сборка установлена; 13.09.2026 владелец подтвердил появление шкалы при первом и повторном повороте. В Mac 2.2.1 шкала также установлена и проверена владельцем.

На Windows отключение GoXLR во время переключения KVM меняет статус в меню без всплывающего предупреждения. После запуска, смены USB, выхода из сна или ручного обновления DeskSwitch повторяет чтение статуса до 12 раз с паузой 1,5 секунды между неудачными ответами; после успеха или исчерпания попыток опрос прекращается. Фоновая проверка не открывает шкалу и не меняет громкость. Очередь старых команд сбрасывается при разрыве связи. Ошибка нового поворота вне восстановления остаётся видимой пользователю.

На Windows восстановление колеса, колёсика под большим пальцем и боковых кнопок MX Master 3S проверяется при запуске, после изменения USB-устройств и выхода из сна: после небольшой задержки выполняется до трёх попыток. После успешной проверки всех функций опрос прекращается. Ручная команда «Восстановить колёса и боковые кнопки MX Master 3S» остаётся в меню.

Настройка каналов, перенос профилей Windows, ручка громкости и расширение USB-портов: **[GoXLR на Mac и Windows](Mac/GoXLR.md)**. При USB-переключении звук прерывается; одновременный звук обоих компьютеров требует другой схемы подключения.

**Известный сбой KVM, 13.09.2026:** после нескольких переходов Windows перестала распознавать GoXLR и показала «Сбой запроса дескриптора устройства», код 43. Отключение только USB-кабеля GoXLR на 10 секунд и подключение обратно восстановило устройство и выбранные профили. Это отдельный сбой распознавания USB; повторные запросы DeskSwitch к Utility его не устраняют. Длительная устойчивость GoXLR через KVM пока не подтверждена. [Проверка и восстановление](Mac/GoXLR.md#windows-неизвестное-usb-устройство-после-kvm).

## Установка на Windows

Скачай `DeskSwitch-Windows.zip` из [Releases](https://github.com/w1zardz/msi-deskswitch/releases/latest), распакуй и запусти `Install.ps1` через PowerShell. Для обновления сначала выбери «Выход» у значка DeskSwitch в трее.

Программа устанавливается в `%USERPROFILE%\.deskswitch` и добавляет ярлык в автозагрузку текущего пользователя. Настройки `goxlr.json` и журнал `status.log` находятся там же. Это общий каталог для ручного запуска и автозагрузки Windows: отдельная копия AppData у пакетного приложения больше не подменяет настройки. При обновлении установщик переносит прежний `%LOCALAPPDATA%\MSI-DeskSwitch\goxlr.json`, только если нового файла ещё нет; существующий новый конфиг имеет приоритет. Администратор не требуется. Исходники собираются `Windows/Build.ps1` компилятором .NET Framework, входящим в Windows. Для ручного запуска достаточно `DeskSwitch.exe`.

Для GoXLR первый импорт сохраняет выбранные профили и явные каталоги Utility в `%USERPROFILE%\.deskswitch\GoXLR-Utility`. После установки Utility запусти `Configure-GoXlrStartup.cmd`: помощник проверяет наличие обоих выбранных профилей и сохраняет ярлык автозапуска с `--config` на этот `settings.json`. Старый отличающийся ярлык предварительно копируется рядом с конфигом. Помощник не запускает и не закрывает программы, не меняет профили; при первом запуске нужно открыть созданный ярлык. Используй его и для последующих ручных запусков, чтобы Utility всегда видела тот же конфиг. Не включай заново обычный автозапуск из меню Utility: он может заменить аргумент конфигурации; вместо этого повтори помощник. Для другого расположения программы или конфига доступны параметры `-UtilityExe` и `-UtilityConfigPath` у `Configure-GoXlrStartup.ps1`.

Сборка текущих исходников с GoXLR публикуется как артефакт `DeskSwitch-Windows` успешного запуска [Windows build and GoXLR checks](https://github.com/w1zardz/msi-deskswitch/actions/workflows/windows-build.yml). Наличие изменений в master не обновляет старые файлы Releases автоматически.

**PageDown → Mac.** Также можно дважды нажать значок в трее или открыть его меню.

## Установка на Mac

**Нативная версия 2.2.1:** приложение **MSI DeskSwitch** для Apple Silicon и macOS 13+. SwiftUI, значок двух экранов в строке меню, без Hammerspoon и Homebrew во время работы. При вращении крутилки GoXLR появляется плашка с подтверждённой громкостью Headphones.

1. Распакуй `DeskSwitch-Mac-Native.zip`, открой `Install.command`. Приложение устанавливается в `~/Applications`.
2. В окне «Настройки» выбери подключённый **MSI MAG322UPF**. Выбор сохраняется по UUID; другой или отключённый монитор автоматически не подставляется.
3. Нажми «Открыть настройки доступа» и включи **MSI DeskSwitch** в **Конфиденциальность и безопасность → Универсальный доступ**. Разрешение выдаёт пользователь. Приложение подхватит его автоматически; если клавиши сразу не заработали, перезапусти приложение. Без разрешения работают кнопки меню.
4. Включи «Запускать DeskSwitch при входе». Закрой окно: переключатель останется в строке меню.

**PageDown → Windows**, **Ctrl+Shift+F11 → Windows**. При необходимости вместо PageDown можно выбрать PageUp. Строка «Получено нажатие» показывает только нажатия PageUp/PageDown, без записи набираемого текста. Оба сочетания срабатывают после отпускания клавиши, без повторного переключения при удержании. PageDown с Ctrl/Shift/Option/Command остаётся обычной клавишей; перехват можно отключить или поставить на паузу. При отключённом выбранном мониторе клавиша не перехватывается.

В строке меню — короткое системное меню перехода в Windows, возврата изображения MacBook и открытия настроек. Настройки находятся в отдельном окне, ограниченном видимой областью текущего экрана; длинное содержимое прокручивается. После сна и переподключения приложение обновляет список устройств. **Автоматически выбирать вход Mac оно не будет:** Windows сохраняет управление до явного переключения. Подтверждение отправки команды не означает подтверждение переподключения USB. Если монитор не сообщает текущий вход, в диагностике он остаётся `unknown`.

Совместимость с Windows сохранена: тот же VCP `0x60`, DisplayPort `15`, USB-C **`16` именно для MAG322UPF**. На Windows продолжает работать существующий DeskSwitch и восстановление колеса MX Master 3S. Сетевая связь между компьютерами не нужна.

При переходе с Hammerspoon убери только строку `deskSwitchMSI = require("desk-switch")` из `~/.hammerspoon/init.lua` и нажми **Reload Config**, чтобы два приложения не перехватывали PageDown одновременно. Остальные настройки Hammerspoon сохраняются.

Сборка из исходников на Mac с Xcode Command Line Tools и Python 3:

```sh
bash Mac/Native/test.sh
bash Mac/Native/build.sh
```

Сборщик скачивает m1ddc 1.2.0 по закреплённому SHA-256, включает его и лицензию в приложение. Приложение имеет локальную ad-hoc подпись, без Apple Developer ID и нотариализации. После обновления macOS может потребовать повторно выдать разрешение клавиатуры. При установке скачанного архива macOS может потребовать разрешить открытие через настройки безопасности; не отключай Gatekeeper целиком.

### Привычная клавиатура на Mac

По умолчанию включены два независимых режима, которые можно отключить в настройках:

- **Windows-сочетания:** Ctrl+C/V/X/A/Z/Y/S/F/O/N/P/W/T/L/R и варианты с Shift работают через соответствующие команды Mac. Ctrl+стрелки влево/вправо и Ctrl+Backspace/Delete перемещают и удаляют по словам. Home/End — начало/конец строки, Ctrl+Home/End — документа. Стандартный Command остаётся доступен; Ctrl+Tab не меняется.
- **Alt+Shift:** меняет включённую раскладку после отпускания обеих клавиш. Если с Alt+Shift нажата другая клавиша, язык не меняется. Используются только уже включённые в macOS источники ввода; для привычной пунктуации подходит «Русская — ПК».

В Terminal, iTerm2, Warp, Alacritty, kitty и WezTerm сохраняются команды оболочки с Ctrl; Ctrl+Shift+C/V выполняют копирование/вставку. Встроенные терминалы других приложений отдельно не распознаются: при необходимости поставь клавиатурные функции на паузу через меню. Режимы действуют на клавиатуры этого Mac и не требуют подключённого MSI. Прошивка NuPhy и настройки Windows не меняются.

[Резервная копия обоих режимов NuPhy](NuPhy/README.md) включает четыре слоя каждого режима и полную память макросов. В публичном репозитории архив зашифрован; ключ восстановления хранится отдельно у владельца.

Надписи на колпачках и назначения в NuPhyIO могут различаться, особенно в Windows-режиме с Mac-колпачками. Не переставляй колпачки разного размера. Cmd+Tab остаётся стандартным переключением приложений macOS; DeskSwitch не заменяет его на Opt+Tab. Перестановка Option/Command в системных настройках одновременно меняет физическую комбинацию смены языка. Для текущей настройки владелец выбрал сохранить прежние назначения модификаторов и уже привычный Alt+Shift.

### Прежний вариант с Hammerspoon

`DeskSwitch-Mac.zip` из старых [Releases](https://github.com/w1zardz/msi-deskswitch/releases) и `Mac/Install.command` по-прежнему доступны. Нужны Apple Silicon и macOS 13+.

1. Распакуй архив и открой `Install.command`.
2. Разреши Hammerspoon управление в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
3. В меню Hammerspoon сверху нажми **Reload Config**. Появится меню **Mac ↔ PC**.

**PageDown → Windows.** Разрешение macOS требуется выдать самостоятельно. Пакет содержит Hammerspoon 1.1.1 и m1ddc 1.2.0; Homebrew и инструменты разработчика для этого варианта не нужны. Установщик проверяет SHA-256 архивов и подпись нового Hammerspoon, сохраняет предыдущую конфигурацию и добавляет строку загрузки модуля. Установленный Hammerspoon сохраняется. Автозапуск включается при загрузке модуля.

Для пользователей Homebrew: `Mac/Install.command` устанавливает зависимости через Homebrew и ту же конфигурацию. Готовый архив из Releases проще.

### Мак с закрытой крышкой не засыпает у монитора

Без этого закрытый MacBook уходит в Clamshell Sleep, когда вход MSI переключён на Windows: PageDown обратно даёт чёрный экран, монитор в режиме Auto возвращается на DisplayPort.

`Mac/Awake/Install.command` (один раз пароль администратора) ставит системный демон:

- пока Мак на питании и виден **MSI MAG322UPF** или его USB-KVM **MSI Gaming Controller**, включён `pmset disablesleep 1`; USB позволяет распознать док до появления монитора в видеодрайвере;
- монитор пропал больше чем на 90 секунд или питание отключено — сон включается обратно, при закрытой крышке Мак засыпает сразу;
- экран пробуждается при первом обнаружении дока, его повторном подключении и возвращении USB-KVM на Мак; уже присутствующий при запуске KVM тоже учитывается;
- при остановке демона сон всегда восстанавливается.

Лог: `/var/log/deskswitch-awake.log`. Удаление: `Mac/Awake/Uninstall.command`.

**Первое подключение закрытого MacBook — отдельный случай.** 22.09.2026 журнал
показал сон на батарее в 19:25, пробуждение от крышки в 19:36:06 и повторный
Clamshell DarkWake в 19:36:16. Старый демон включил защиту в 19:36:22, но
полноценное пробуждение произошло лишь в 19:39:50. USB-C оставался
`transportRestricted: YES` до `Policy Authorized` в 19:39:58; KVM появился
в журнале демона в 19:40:00. Это подтверждённые события, а не доказательство
того, что любой чёрный экран вызван одной и той же причиной.

Проверить «Системные настройки → Конфиденциальность и безопасность →
Аксессуары». Apple требует предварительно разрешить монитор, мышь и клавиатуру
для работы с закрытой крышкой: [инструкция Apple](https://support.apple.com/en-us/102282).
«Всегда разрешать» снимает запросы для **всех** проводных аксессуаров; менять
эту защиту только по явному решению владельца. Демон не обходит разрешения USB,
FileVault или пароль и не исполняется во время полного сна.

Обновление обычного `.app` не обновляет системный демон: после изменения
`Mac/Awake/deskswitch-awake.sh` повторно запустить **Mac/Awake/Install.command**.
Проверки автоматики без изменения питания компьютера: `bash Mac/Awake/test-awake.sh`.
Физическая проверка: уснувший закрытый Mac → подключить USB-C при Windows на MSI →
PageDown → изображение Mac без открытия крышки. Успех автотестов эту проверку не заменяет.

## Исправление колёс и боковых кнопок MX Master 3S

После переноса Bolt между компьютерами мышь может сохранять режим HID++: обычные щелчки и движение работают, а вращение колеса не поступает в Windows. Режим высокой точности также может давать неправильную скорость прокрутки.

Windows-версия проверяет мышь при запуске, после уведомлений USB и повторно в фоне: приёмник может появиться раньше, чем сама мышь проснётся. Она находит **MX Master 3S** на **Logi Bolt `046D:C548`**, запрашивает индекс HID++ feature `0x2121` и возвращает колесо в обычный режим HID с обычной точностью. Feature `0x2150` — колёсико под большим пальцем: снимается только перенаправление вращения в Logitech, чтобы снова работала горизонтальная прокрутка. Также проверяется feature `0x1B04`: у Back и Forward снимается только временное перенаправление в Logitech, чтобы Windows снова получала Mouse4/Mouse5. Изменения проверяются повторным чтением. Направление прокрутки обоих колёс, SmartShift, магнитные щелчки, чувствительность указателя, назначения и остальные флаги кнопок, другие кнопки и спаривание сохраняются. Если запущен Logitech Options, управление мышью остаётся ему.

В меню трея есть «Восстановить колёса и боковые кнопки MX Master 3S». Другие модели автоматически не перенастраиваются.

Если **колёсико под большим пальцем не листает влево/вправо** ни на Windows, ни на Mac, причина может быть в самой мыши: 24.09.2026 чтение `0x2150` показало перенаправление в HID++ (режим `1`). Режим хранится в мыши и переходит через KVM на оба компьютера. DeskSwitch вернул `1 → 0` с сохранением направления, повторное чтение подтвердило `0`. После следующего сеанса на Mac колёсико вернулось снова перенаправленным, и DeskSwitch восстановил его автоматически: режим включается на стороне Mac, программа пока не определена, и горизонтальная прокрутка на Mac зависит от неё. Физическая проверка владельцем на момент записи ожидается. Подробности и протокол — в [памятке](Windows/MX-Master-3S.md#если-не-работает-горизонтальная-прокрутка-колёсико-под-большим-пальцем).

При диагностике 17.09.2026 подтверждён пропуск ответа Bolt после прежнего ожидания 650 мс: ответ появлялся уже во время следующего запроса, и DeskSwitch сообщал, что мышь недоступна. Ожидание ответа увеличено до 1800 мс; запросы различаются ненулевыми software ID, чтобы запоздавший ответ на один поиск feature не подменял другой. Проверки остаются ограниченными тремя попытками после события USB/запуска/пробуждения, постоянного опроса нет. Регрессионные проверки: `Windows/Test-WheelRepair.ps1`.

Если **боковые кнопки MX Master 3S не переключают паузу OBS**, хотя Mouse4/Mouse5 назначены правильно, проверь отдельный режим перенаправления кнопок HID++ `0x1B04`. После подтверждённого повторения 17.09.2026 его восстановление добавлено в ту же ограниченную автопроверку, что и колесо. Успех колеса при ошибке проверки кнопок больше не завершает попытки. Причина, точное восстановление и границы проверки сохранены в [памятке по боковым кнопкам](Windows/MX-Master-3S.md).

## Диагностика

```powershell
DeskSwitch.exe status input.txt
DeskSwitch.exe wheel-status wheel.txt
DeskSwitch.exe repair-wheel wheel.txt
DeskSwitch.exe mouse-status mouse.txt
DeskSwitch.exe repair-mouse mouse.txt
DeskSwitch.exe mac
DeskSwitch.exe windows
```

`status` читает вход монитора. Команды `mac` и `windows` немедленно меняют вход. Журнал Windows: `%USERPROFILE%\.deskswitch\status.log`. Журнал установки Mac: рядом с `Install.command`.

В нативном приложении Mac: «Настройки → Копировать диагностику». Последние ошибки также доступны в системном журнале с subsystem `ru.w1zardz.msi-deskswitch`. Проверь разрешение DeskSwitch, выбранный MSI, USB-C и DDC/CI. Для старого варианта проверь разрешение Hammerspoon и Reload Config. В меню самого монитора можно вручную выбрать DisplayPort.

## Удаление

Windows: выйди из приложения, удали ярлык `MSI DeskSwitch.lnk` из автозагрузки и файл `%USERPROFILE%\.deskswitch\DeskSwitch.exe`. Там же можно удалить только настройки DeskSwitch `goxlr.json` и `status.log`. Каталог `GoXLR-Utility` содержит отдельные профили и настройки звука; сохрани его, если продолжаешь использовать Utility. При переходе со старой установки может остаться `%LOCALAPPDATA%\MSI-DeskSwitch`.

Mac, нативная версия: выключи «Запускать при входе», нажми «Выйти», удали `~/Applications/MSI DeskSwitch.app`. Сохранённые настройки можно удалить командой `defaults delete ru.w1zardz.msi-deskswitch`.

Mac, Hammerspoon: убери `deskSwitchMSI = require("desk-switch")` из `~/.hammerspoon/init.lua`, затем Reload Config. При необходимости удали `desk-switch.lua` и `desk-switch-bin`. Резервные копии прежних файлов создаются с суффиксом `.backup-...`. Автозапуск Hammerspoon можно выключить в его настройках.
