# GoXLR, NuPhy и OBS на Windows

Рекомендуемая схема для записи с последующим монтажом: **ручка NuPhy регулирует только Headphones GoXLR**, нажатие остаётся **Delete**. Уровни записи регулируются источниками OBS. Обновление репозитория и установка DeskSwitch на Mac не обновляют запущенную Windows-копию: на ПК нужно установить Windows-пакет и настроить подключение к Utility.

## Сначала подключить ручку на Windows

1. Перенеси выбранные основной и микрофонный профили перед первым запуском Utility. В персональном комплекте это делает `Import-GoXlrProfiles.cmd` с отдельным manifest. Он не назначает первый попавшийся микшер.
2. Установи и запусти GoXLR Utility. Официальный GoXLR App одновременно работать не должен; его драйвер сохраняется. Автозапуск Utility включи, официального App — отключи.
3. Установи актуальный DeskSwitch через `Install.cmd`. В его меню должно быть выбрано управление Headphones нужного GoXLR. Пока функция выключена или работает старая сборка, вращение остаётся обычной системной громкостью Windows.
4. На тихом звуке проверь движение **Headphones** в Utility при вращении. Системный индикатор Windows сам по себе не подтверждает управление наушниками.

Включённая функция при недоступном выбранном GoXLR не переключается на системную громкость. Это позволяет отличить отсутствие связи от ещё не включённого управления. Mute остаётся отдельной командой или кнопкой интерфейса, не нажатием ручки.

## Как разделить звук

| Что звучит | Выход приложения в Windows | Слышно в GoXLR | Отдельный источник OBS |
| --- | --- | --- | --- |
| Windows, браузер, обычные программы | System (GoXLR) | Headphones | Захват выходного аудиопотока System |
| Игра | Game (GoXLR) | Headphones | Захват выходного аудиопотока Game |
| Discord и другие собеседники | Chat (GoXLR) | Headphones | Захват выходного аудиопотока Chat |
| Музыкальный плеер | Music (GoXLR) | Headphones | Захват выходного аудиопотока Music |
| Твой микрофон | Вход Chat Mic (GoXLR) | Прослушивание голоса по желанию; не включать автоматически | Существующий источник микрофона с его фильтрами |

В GoXLR Router для этой схемы System, Game, Chat и Music должны идти в **Headphones**. **Chat Mic — только Microphone**: сэмплы и звук ПК туда не добавляются, чтобы запись голоса и собеседники получали именно микрофон. Если звуковая панель действительно нужна в звонках, это отдельное осознанное изменение этой схемы.

Практичное назначение четырёх физических фейдеров: **Mic / Game / Chat / Music** с такими же подписями. Наушники регулируются крутилкой NuPhy. Это предложение для нового отдельного профиля, а не описание уже применённой настройки. Не меняй исходный профиль до проверки существующей записи OBS.

После подключения Headphones системную громкость Windows можно оставить фиксированной. Поднимать её до 100% следует только после уменьшения Headphones до тихого уровня, затем выбрать комфортную громкость наушников. Не пытайся выравнивать запись постоянными изменениями громкости наушников.

## Дорожки OBS

| Дорожка | Состав |
| --- | --- |
| 1 | Готовый общий звук: микрофон + игра + собеседники + System |
| 2 | Только микрофон |
| 3 | Только игра |
| 4 | Только собеседники |
| 5 | Только System: браузер и остальные программы |
| 6 | Только музыка, чтобы добавить её при монтаже отдельно |

В «Расширенных свойствах аудио» каждый источник назначается на общий трек 1 и свой отдельный трек. В этой рекомендации музыка идёт только на 6. В настройках записи нужно также включить соответствующие дорожки; назначение галочек источникам само по себе их не записывает. Для записи подойдёт MKV с последующим ремультиплексированием в MP4 при необходимости. Обычный проигрыватель воспроизводит одну дорожку: поэтому общий трек нужен для просмотра без монтажа. См. [официальную инструкцию OBS по нескольким аудиодорожкам](https://obsproject.com/kb/multiple-audio-track-recording-guide).

**Каждый звук захватывается один раз.** Когда добавлены отдельные System/Game/Chat/Music, глобальный Desktop Audio, захват звука той же игры через Game Capture/Application Audio и другие дубли нужно отключить. Не добавляй одновременно Broadcast Stream Mix и источники, которые в него уже входят. Существующие источники нужно сначала проверить: их нельзя удалять вслепую вместе с фильтрами и привязками к сценам. См. также [официальное описание аудиоисточников OBS](https://obsproject.com/kb/audio-sources).

Для звука, который уже слышен через прямую маршрутизацию GoXLR, в OBS оставь «Мониторинг выключен». Иначе можно получить повторное прослушивание с задержкой. Запись источника при этом продолжает работать.

У микрофона сначала сохраняем нынешний тип, усиление, EQ, gate/compressor GoXLR и цепочку фильтров OBS. Профиль `.goxlrMicProfile` не переносит VST Fresh Air / Saturation Knob, которые стоят отдельно в OBS. Уровень проверяем по речи: ориентир для пиков после обработки — примерно −12…−6 dBFS, без достижения 0 dBFS. Подгонять все голоса одним процентом громкости нельзя.

## Что обнаружено в переданном профиле

В сохранённом снимке Color от 12.09.2026 Game и Music выключены в Headphones; BroadcastMix содержит только Microphone и Samples; ChatMic также содержит Samples. Фейдер A подписан System, хотя управляет Headphones, а C подписан Voice Chat, хотя управляет Game. Это объясняет возможную путаницу, но не является чтением текущих настроек Windows.

Поэтому сначала нужен отчёт Windows: выбранные устройства и источники OBS, фильтры, дорожки и текущая маршрутизация Utility. Только после этого можно подготовить отдельный профиль для записи, не потеряв существующий голос и сцены.

## Отчёт перед настройкой OBS

Запусти `Export-AudioSetup.cmd` из Windows-пакета. На рабочем столе появится JSON с выбранными аудиоустройствами, дорожками, названиями фильтров, состоянием DeskSwitch и маршрутизацией выбранного GoXLR. Если текущие профиль или сцены OBS не определяются, помощник предложит явный выбор.

Экспорт не меняет звук, сцены, профили или процессы. Он не читает файлы стримингового сервиса и пароли OBS WebSocket, не включает адреса браузерных источников и двоичные данные VST. Отчёт никуда автоматически не отправляется. Это диагностика звука, а не полная резервная копия OBS.
